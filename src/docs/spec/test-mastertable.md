# 基本的な処理の内容
- 「指示されたマスタテーブル」のデータ件数を確認するD層（個別Dao）、B層を作成する。
- 上記処理を画面Aの件数確認ボタンから実行し、結果をOKメッセージ・ダイアログを使用してデータ件数を表示する。
- 画面Aから画面遷移ボタンを押下すると画面Bに遷移する。

- 次に、既存のB層から「指示されたマスタテーブル」の一覧を取得する処理を書く（D層はCmnDaoを使用する）。この処理を画面Bから実行し、一覧に表示する。
- そして、既存のB層から「指示されたマスタテーブル」のDaoをCLIで自動生成しC(R)UD処理を実装できるようにする（Rは一覧表示で実装済みなのでCUDを新規実装）。
- このC(R)UD処理は、GridViewを使用し、グリッド中に削除ボタンを設けグリッド行削除、（フッタ部ではない）グリッド外に追加ボタンを設けグリッド行追加。
- 画面Bの更新ボタンを押下するとYES/NOメッセージ・ダイアログが表示され、YES押下後に更新処理を実行する。
