# 基本的な処理の内容
- 「指示されたマスタ・テーブル」のデータ件数を確認するD層（個別Dao）、B層を作成する。
- 上記処理を画面Aの件数確認ボタンから実行し、結果をOKメッセージ・ダイアログを使用してデータ件数を表示する。
- 画面Aから画面遷移ボタンを押下すると画面Bに遷移する。

- 次に、既存のB層から「指示されたマスタ・テーブル」の一覧を取得する処理を書く（D層はCmnDaoを使用する）。この処理を画面Bから実行し、一覧に表示する。
- そして、既存のB層から「指示されたマスタ・テーブル」のDaoをCLI（スキルを使用）で自動生成し、既存のB層からCRUD処理の実装を準備する。
- 残りのCUD処理は、GridViewを使用し、グリッド中に削除ボタンを設けグリッド行削除、（フッタ部ではない）グリッド外に追加ボタンを設けグリッド行追加。
- 画面Bの更新ボタンを押下するとYES/NOメッセージ・ダイアログが表示され、YES押下後にバッチ更新処理(CUD）を実行する。
