# 基本的な処理の内容
「指示されたトランザクション・テーブル」の条件検索、詳細表示、更新処理を実装する。

- 「指示されたトランザクション・テーブル」の一覧を取得する条件検索処理を既存のB層に書く（D層はCmnDaoを使用する）。
- この処理を検索条件を入力可能にした画面Aから実行し、一覧に表示する（SQLでマスタ・テーブルとJOINして表示値に変換しておく）。

- 画面Aの画面遷移ボタン（押下すると画面Bに遷移する）を実装する。

- 「指示されたトランザクション・テーブル」のDaoをCLIで自動生成（スキルを使用）し「既存のB層」からCRUD処理を実行する準備をする（既存が在ればソレを使用）。
- 画面Bの初期処理で「指示されたトランザクション・テーブル」の項目中の「マスタ・テーブル値入力用DDL」を生成するためマスタ・テーブルのデータを取得する。
- 画面Aの詳細ボタンから画面Bに遷移した場合「指示されたトランザクション・テーブル」のデータを詳細表示するため自動生成Daoで参照(R)処理を実行する。
- 画面Aの詳細ボタンから遷移した場合は、画面BのCRUDのUD（編集・削除）、画面Aの追加ボタンから遷移した場合は、画面BのCRUDのC（追加）を実行するボタンを活性にする。
- 画面BのCUD処理ボタンを押下するとYES/NOメッセージ・ダイアログが表示され、YES押下後にCUD処理を実行する。
