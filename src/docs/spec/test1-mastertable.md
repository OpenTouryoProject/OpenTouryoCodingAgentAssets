# 基本的な処理の内容
「指示されたマスタ・テーブル」          の件数確認処理とバッチ更新処理を実装する。

- 「指示されたマスタ・テーブル」          のデータ件数を確認するSQLをCmnDao経由で実行するB層を作成する。
- 上記処理を画面Aの件数確認ボタンから実行し、結果をOKメッセージ・ダイアログを使用してデータ件数を表示する。

- 画面Aの画面遷移ボタン（押下すると画面Bに遷移する）を実装する。





- 「指示されたマスタ・テーブル」          のDaoをCLIで自動生成（スキルを使用）し「既存のB層」からCRUD処理を実行する準備をする。
- 画面Bから「指示されたマスタ・テーブル」の「自動生成Dao」の参照（R）処理を「既存のB層」経由で実行し、取得したデータを一覧に表示する。
- バッチ更新(CUD)処理は、グリッドを使用し、グリッド中でデータ・メンテナンス（行の追加、更新、削除）を行う（各ボタンの配置はスキルに準拠）。
- 画面Bのバッチ更新ボタンを押下するとYES/NOメッセージ・ダイアログが表示され、YES押下後にバッチ更新(CUD)処理を「既存のB層」「自動生成Dao」経由で実行する。
