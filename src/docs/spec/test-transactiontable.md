# 基本的な処理の内容
- 「指示されたトランザクション・テーブル」の条件検索を行うD層（個別Dao）、B層を作成する。
- 上記処理を画面Aの条件検索ボタンから実行し、結果をGridViewに一覧を表示する。この際、マスタ・テーブルを使用して表示値に変換する。
- GridViewにはグリッド中のレコード毎に詳細ボタン、枠外に追加ボタンを配置してあり、コレらのボタンを押下すると画面Bに遷移する。

- 最初に「指示されたマスタ・テーブル」のDaoをCLI（スキルを使用）で自動生成し、既存のB層からCRUD処理の実装を準備する。
- なお、画面Bの入力では「指示されたトランザクション・テーブル」中のマスタ・テーブル値はドロップダウンリストの表示値を使用する。
- 画面Aの詳細ボタンから画面Bに遷移した場合「指示されたトランザクション・テーブル」のデータを詳細表示する(CRUDのRを実行）。
- 画面Aの詳細ボタンから遷移した場合は、画面BのCRUDのUD、画面Aの追加ボタンから遷移した場合は、画面BのCRUDのCを実行するボタンを活性にする。
- 画面BのCUD処理ボタンを押下するとYES/NOメッセージ・ダイアログが表示され、YES押下後にCUD処理を実行する。
