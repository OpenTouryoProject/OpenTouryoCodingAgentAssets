# 基本的な処理の内容
- 「指示されたトランザクション・テーブル」の条件検索を行うD層（個別Dao）、B層を作成する。
- 上記処理を画面Aで条件入力と条件検索ボタンから条件検索を実行し、結果をグリッドに一覧を表示する。この際、マスタ・テーブルとJOINして表示値に変換する。
- グリッドにはグリッド中のレコード毎に詳細ボタン、枠外に追加ボタンを配置してあり、コレらのボタンを押下すると画面B（子画面相当）に遷移する。

- 指示されたトランザクション・テーブル」のDaoをCLI（スキルを使用）で自動生成し、既存のB層からCRUD処理の実装を準備する。
- 画面Bの「指示されたトランザクション・テーブル」中のマスタ・テーブル値入力用ドロップダウンリストは既存のB層／同様にCLIで自動生成したDaoを使用して取得する。
- 画面Aの詳細ボタンから画面Bに遷移した場合「指示されたトランザクション・テーブル」のデータを詳細表示する(CRUDのRを実行）。
- 画面Aの詳細ボタンから遷移した場合は、画面BのCRUDのUD（編集・削除）、画面Aの追加ボタンから遷移した場合は、画面BのCRUDのC（追加）を実行するボタンを活性にする。
- 画面BのCUD処理ボタンを押下するとYES/NOメッセージ・ダイアログが表示され、YES押下後にCUD処理を実行する。
