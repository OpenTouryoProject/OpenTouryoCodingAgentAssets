# 基本的な処理の内容
「指示されたトランザクション・テーブル」の件数確認処理とバッチ更新処理を実装する。

- 「指示されたトランザクション・テーブル」のデータ件数を確認するSQLをCmnDao経由で実行するB層を作成する。
- 上記処理を画面Aの件数確認ボタンから実行し、結果をOKメッセージ・ダイアログを使用してデータ件数を表示する。

- 画面Aの画面遷移ボタン（押下すると画面Bに遷移する）を実装する。

- 「指示されたトランザクション・テーブル」の一覧を取得する条件検索処理を既存のB層に書く（D層はCmnDaoを使用する）。
- この処理を検索条件を入力可能にした画面Bから実行し、一覧に表示する（マスタ・テーブル関連項目をDDL化するので、同時にマスタ・テーブルのデータも取得）。
- 一覧は20ページ毎にページングし、バッチ更新処理が開始されたら、ページングを止めて処理対象を、当該結果セットに限定する。

- 「指示されたトランザクション・テーブル」のDaoをCLIで自動生成（スキルを使用）し「既存のB層」からCUD処理を実行する準備をする。

- バッチ更新(CUD)処理は、グリッドを使用し、グリッド中でデータ・メンテナンス（行の追加、更新、削除）を行う（各ボタンの配置はスキルに準拠）。
- 画面Bのバッチ更新ボタンを押下するとYES/NOメッセージ・ダイアログが表示され、YES押下後にバッチ更新(CUD)処理を「既存のB層」「自動生成Dao」経由で実行する。
