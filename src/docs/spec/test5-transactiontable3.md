# 基本的な処理の内容
「指示されたトランザクション・テーブル」の詳細表示に「明細トランザクション・テーブル」を追加し更新処理でバッチ更新する。

- 「明細トランザクション・テーブル」のDaoをCLIで自動生成（スキルを使用）し「既存のB層」からCRUD処理を実行する準備をする。
- 画面Aの詳細ボタンから画面Bに遷移した場合「明細トランザクション・テーブル」のデータを明細表示するため自動生成Daoで参照(R)処理を実行する。
- バッチ更新(CUD)処理は、グリッドを使用し、グリッド中でデータ・メンテナンス（行の追加、更新、削除）を行う（各ボタンの配置はスキルに準拠）。
- 画面BのCUD処理ボタンを押下するとYES/NOメッセージ・ダイアログが表示され、YES押下後に親テーブルの更新と子テーブル（明細）のバッチ更新を実行する。
