## テスト先行
対象の仕様を、テスト仕様 → Red → Green で実装する（`TESTING.md`）。指示を受けたセッションが**司令役**になり、
実装役・レビュー役（`.claude/agents` のサブ エージェント）を回す（"..\plan\test6-testfirst.md"）。
**人は、司令役が上げる仕様の決定のレポートにだけ GO/NOGO を返す**（ほかに、管理者の権限が要る操作を頼まれることがある）。

- MVC_Sample  
  "..\plan\test6-testfirst.md" の手順で、司令役として "..\spec\test6-testfirst-OrdTf.md" を ケース1 で実行して下さい。
- MVC_Sample_Core  
  "..\plan\test6-testfirst.md" の手順で、司令役として "..\spec\test6-testfirst-OrdTf.md" を ケース2 で実行して下さい。
- WebForms_Sample  
  "..\plan\test6-testfirst.md" の手順で、司令役として "..\spec\test6-testfirst-OrdTf.md" を ケース3 で実行して下さい。

決定のレポートに答えるときは、レポートの GO / NOGO の欄に書き込んで、次のように返す。
- 「決定のレポートに GO / NOGO を書きました。続けて下さい。」

仕様（NorthwindDbSampleSpec）が更新されたとき（NOGO で直した、決定記録に記録した）は、次のように指示する。
- 「仕様が <新しい版> に更新されました。"..\plan\test6-testfirst.md" の「仕様の更新」を行って下さい。」
