## テスト先行
対象の仕様を、テスト仕様 → Red → Green で実装する（`TESTING.md`）。指示を受けたセッションが**司令役**になり、
実装役・レビュー役（`.claude/agents`。Copilot は `.github/agents` のサブ エージェント）を回す（"..\plan\cmn-testfirst.md"）。
**人は、司令役が聞く仕様の決定にだけ答える**（決定のレポートを読みながら、選択肢で答える。ほかに、決定記録のコミットと、管理者の権限が要る操作を頼まれることがある）。
**司令役は新しいセッションで始める**（セットアップなど別の作業をしたセッションで続けない。関係の無い文脈を持ち込まず、使用量も食わない）。

- MVC_Sample  
  "..\plan\cmn-testfirst.md" の手順で、司令役として "..\spec\test3-testfirst-OrdTf.md" を ケース1 で実行して下さい。
- MVC_Sample_Core  
  "..\plan\cmn-testfirst.md" の手順で、司令役として "..\spec\test3-testfirst-OrdTf.md" を ケース2 で実行して下さい。
- WebForms_Sample  
  "..\plan\cmn-testfirst.md" の手順で、司令役として "..\spec\test3-testfirst-OrdTf.md" を ケース3 で実行して下さい。

司令役が決定記録の案を仕様のリポジトリに書いたら、確かめてコミットし、次のように返す。
- 「決定記録を <新しい版> でコミットしました。続けて下さい。」

NOGO で仕様を直したときは、次のように指示する。
- 「仕様が <新しい版> に更新されました。"..\plan\cmn-testfirst.md" の「仕様の更新」を行って下さい。」
