## 基本的な処理
「使用するフレームワーク毎の[共通仕様](../spec/test1-framework.md)」と「[テスト先行のサンプル仕様](../spec/test6-testfirst.md)」に従い、
**次の段を順に行う。段 1・段 2 の終わりで止まり、人の承認を待つ。**

1. **段 1：テスト仕様** — 仕様の出どころを読み、`docs/spec/test6-testfirst-<フレームワーク>-tests.md` に B層のテストケースを書く（各ケースに根拠の ID）。
   根拠の ID を付けられない点・仕様の曖昧な点は、一覧にして人に返す。**ここで止まる。**
2. **段 2：テスト（Red）** — 承認されたテスト仕様から、テストのプロジェクトとテストを書く（`opentouryo-test-layer-b`）。
   引数クラス・戻り値クラスと、戻り値を設定するだけの空の `UOC_OrdTfSearch` を置き、**テストがアサーションで失敗すること**を確かめて結果を示す。**ここで止まる。**
3. **段 3：計画** — `docs/plan/test6-testfirst-<フレームワーク>.md` に、B層（CmnDao の SQL）と画面の作り方を書く。
4. **段 4：実装（Green）** — テストが通るまで B層を実装し、画面から呼ぶ。**テストのプロジェクトは編集しない**（直す必要があると思ったら、理由を書いて止まる）。
   最後に、テストの結果（件数・合格）と画面の動作を示す。

コミットは人が行う。コミット メッセージの文案を出すときは、トレーラーの決まり（`AGENTS.md`）に従う。
