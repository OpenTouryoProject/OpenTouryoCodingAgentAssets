# コメント／ファイルヘッダ テンプレート（コピー元）

出典：`Samples/WebApp_sample/.../Business/LayerB.cs`（C#）・`VB/Samples/2CS_sample/.../Business/LayerB.vb`（VB）で裏取り。
**バナー行は接頭辞（C#＝`//`／VB＝`'`）＋`*`×82。** UTF-8 BOM 付きで保存する。**on-demand 参照**（SKILL 予算外）。

## C#（`.cs`）ファイルヘッダ

```csharp
//**********************************************************************************
//* フレームワーク・テストクラス（Ｂ層）
//**********************************************************************************

// （任意の補足。例：テスト用クラスなので、必要に応じて流用 or 削除して下さい。）

//**********************************************************************************
//* クラス名        ：LayerB
//* クラス日本語名  ：Ｂ層のテスト
//*
//* 作成日時        ：2026/07/26
//* 作成者          ：（作成者名）
//* 更新履歴        ：
//*
//*  日時        更新者            内容
//*  ----------  ----------------  -------------------------------------------------
//*  2026/07/26  ＸＸ ＹＹ         新規作成
//**********************************************************************************

using System;
using Touryo.Infrastructure.Business.Business;

namespace MyApp
{
    /// <summary>Ｂ層のテスト</summary>
    public class LayerB : MyFcBaseLogic
    {
        /// <summary>業務処理を実装</summary>
        /// <param name="parameterValue">引数クラス</param>
        /// <param name="returnValue">戻り値クラス</param>
        protected override void UOC_DoAction(BaseParameterValue parameterValue, ref BaseReturnValue returnValue)
        {
            // インライン コメントは言語仕様どおり（C# は //）
        }
    }
}
```

## 更新履歴の追記（改修のたびに行を足す・消さない）

```text
//*  日時        更新者            内容
//*  ----------  ----------------  -------------------------------------------------
//*  2026/07/26  ＸＸ ＹＹ         新規作成
//*  2026/08/01  ＡＢ ＣＤ         〇〇機能を追加
```

- 列幅：`日時`＝`----------`（10）／`更新者`＝`----------------`（16）／`内容`＝残り。
- `所属機能名` バナーは、そのファイルのレイヤ（例：`（Ｐ層）`／`（Ｂ層）`／`（Ｄ層）`）を示す。

## インラインの節区切り（`↓`/`↑`）

出典：`LayerD.cs`（D層＝`DBアクセス`）・`LayerB.cs`（B層＝`業務処理`）・`Bat_sample/Program.cs`（呼び出し側＝`B層実行：〈説明〉`）。
**UOC（User Own Coding。スケルトンを除く、開発者が書く＝処理変更時の修正範囲）** を開始 `↓`／終了 `↑` の対で囲む。**ラベル後をダッシュで埋めて幅を揃える**（短いラベルは `-`×53、長いラベルは減らす）。コードのインデントに合わせる。`↓`〜`↑` の外はスケルトン＝そのまま。

```csharp
// D層（個別Dao のメソッド内）：SQL 設定〜実行を囲む
// ↓DBアクセス-----------------------------------------------------

this.SetSqlByFile2("Xxx.xml");            // SQL を設定
this.SetParameter("P1", p.ShipperID);     // パラメタを設定
int cnt = this.ExecInsUpDel_NonQuery();   // 実行（or ExecSelectFill_DT 等）

// ↑DBアクセス-----------------------------------------------------
```

```csharp
// B層（業務クラスのメソッド内）：業務ロジック本体を囲む
// ↓業務処理-----------------------------------------------------

// … 引数の検証・Dao 呼び出し・戻り値の設定 など …

// ↑業務処理-----------------------------------------------------
```

```csharp
// 呼び出し側（P層／バッチ Program）：B層呼び出し区間を囲む。「：」の後に何を実行するか
// ↓B層実行：主キー値を全て検索(ORDER BY 主キー)-----------------------------------------------------

returnValue = (TestReturnValue)CallController.Invoke("LayerB", parameterValue);

// ↑B層実行：主キー値を全て検索(ORDER BY 主キー)-----------------------------------------------------
```

> `.aspx` / `.master` はバナー不要（`<%@ Page … %>` で始まる）。コメントは `<!-- -->`／`<%-- --%>`。
> 自動生成 Dao 等はツールがヘッダを生成する（手で足さない）。
